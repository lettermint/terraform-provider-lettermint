# Security Policy

## Report a Security Issue

Do not report a security issue in a public GitHub issue.

Email [help@lettermint.co](mailto:help@lettermint.co). Use `Security report: Terraform provider` as the subject.

Include this information when possible:

- The affected provider version
- The security impact
- The steps to reproduce the issue
- A small proof of concept
- A proposed correction, if available

Remove tokens, secrets, customer data, and other sensitive values from logs and examples.
