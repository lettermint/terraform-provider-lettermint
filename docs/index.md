# Lettermint Provider

Use the Lettermint provider to manage email infrastructure in one Lettermint team.

Terraform 1.14 or later is required because this provider contains actions.

Set `LETTERMINT_TEAM_TOKEN` or configure `team_token`.

```terraform
terraform {
  required_version = ">= 1.14.0"

  required_providers {
    lettermint = {
      source = "lettermint/lettermint"
    }
  }
}

provider "lettermint" {}
```

## Rate Limits

The Lettermint Team API limits how many requests a team token can make per minute. See [Working with rate limits](https://lettermint.co/docs/platform/teams/team-api/reference#working-with-rate-limits) for the current limits.

When the API answers with `429 Too Many Requests`, the provider waits for the `Retry-After` duration and sends the request again. It retries up to 8 times by default. Set `max_retries` or `LETTERMINT_MAX_RETRIES` to change this, or set `0` to turn retries off. Run Terraform with `TF_LOG=WARN` to see each retry.

A plan reads every resource in the state, so a large configuration can reach the limit. To make fewer requests per minute:

- Lower the number of parallel operations, for example `terraform plan -parallelism=2`.
- Skip the refresh with `terraform plan -refresh=false` when you only need to check your changes.
- Split a large configuration into smaller states.
